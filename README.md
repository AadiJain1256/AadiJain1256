## 🔮 FORESIGHT — Store-SKU Demand Forecasting System

An end-to-end machine learning system for forecasting product demand at the **store-SKU level**.

### What it does

* Integrates **sales, store and SKU datasets**
* Performs data cleaning and integration
* Builds temporal and business-relevant features
* Trains machine learning models for demand forecasting
* Uses **LightGBM** for predictive modeling
* Stores models and processed data using **Joblib & Parquet**
* Provides a deployed **Streamlit interface** for predictions

**Tech:** Python • Pandas • NumPy • LightGBM • Joblib • Parquet • Streamlit

## 🤖 AgentReady — AI-Agent Reliability & Testing Platform

An independent project focused on making AI agents more **reliable, testable and recoverable**.

### What it does

* Tests complete **AI-agent journeys** rather than isolated outputs
* Uses semantic retrieval to work with product information
* Validates structured constraints such as **price, availability and category**
* Injects realistic failure scenarios
* Detects and diagnoses failures
* Identifies recoverable issues and applies fixes
* Reruns failed journeys to verify recovery
* Produces structured **failure and readiness results**

**Tech:** Python • Streamlit • LLM APIs • Embeddings • Semantic Retrieval • FAISS / Chroma • Pandas
